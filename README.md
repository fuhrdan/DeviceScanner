Device Health Dashboard is a lightweight Java desktop application that provides a real-time, windowed view of all hardware devices connected to a Windows system. Using PowerShell and Windows Plug and Play (PnP) data, the dashboard enumerates devices such as USB peripherals, audio interfaces, storage controllers, and network adapters, and visually indicates their operational status with intuitive green (working), yellow (needs attention), and red (not working) indicators. Built with standard Java and Swing and designed to run directly from the command line, this project demonstrates practical OS integration, robust device status parsing, and a clean, extensible architecture suitable for monitoring, diagnostics, or further platform-specific tooling.
